# Changelog

## v1.0.0 - 2026-09-13

- Initial public reproducibility release.
- Includes PostgreSQL cohort, exposure, outcome, and covariate queries.
- Includes the complete R analysis, sensitivity-analysis, validation, and reporting workflow.
- Adds frozen benchmark checks for 9,662 procedure-ICU pairs, 1,939 primary-cohort patients, and 322 events.
- Contains code and documentation only; no source data or patient-level derived data are distributed.
